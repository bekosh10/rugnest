# Tamnun Signs (תמנון – שילוט)

תוכנה (Windows / Mac) שמסדרת קבצי שילוט של תמנון לפי טבלת ההזמנה.

- גוררים: הטבלה (xlsx), הזמנת העבודה (PDF), קבצי העיצוב (PDF – עמוד לשלט).
- הטבלה קובעת: כל שורה עם כמות → קובץ אחד, `<פורמט> - <צבע> <שילוט>[ - דו צדדי] x<כמות>.pdf`.
- תיקיות: דיגיטל | אפי מגנטי | דורסט. קבצים שהתוכנה יצרה (החלפת צבע / מספר) מתחילים ב-`!!!!!!!!!!`.
- `index.html` + `core.js` + `version.json` – מתעדכנים מכאן בכפתור "יש גרסה חדשה". בכל שינוי מעלים את `version` ב-`version.json`.
- `desktop/` – מעטפת Electron. בבנייה מעתיקים את `index.html`, `core.js`, `version.json` אל `desktop/app/`.
