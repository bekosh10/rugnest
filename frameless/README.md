# מערכת לפריימלסים (Frameless)

תוכנה למק שמגדילה קבצי PDF לדפוס (מתיחה לקצה, זיהוי 1:10, טקסט עברי בקווי מתאר) ומכינה סקיצה.

- `index.html` + `version.json` – מתעדכנים מכאן בכפתור "יש גרסה חדשה". בכל שינוי מעלים את `version` ב-`version.json`.
- `desktop/` – מעטפת Electron. בבנייה מעתיקים את `index.html` ו-`version.json` אל `desktop/app/`.
- קובץ ג'וב: `.pdfjob` (לחיצה כפולה פותחת אותו בתוכנה).
